# Contributing

This is a personal GitHub profile repository, so there's no feature roadmap
to contribute to in the traditional sense — but tooling improvements are
welcome.

## What's welcome

- Bug fixes to the GitHub Actions workflows (`.github/workflows/*.yml`)
- Improvements to the static SVG assets in `assets/`
- Suggestions for better-maintained or more reliable widget services
- Accessibility or rendering fixes
- Typo fixes in `README.md`, `SETUP.md`, or these community-health files

## What's probably not a fit

- Changes to the personal content itself (bio, certifications, project
  descriptions) — that's specific to the repository owner
- New third-party widgets added without a note on why the existing set
  doesn't already cover the need

## How to contribute

1. Fork the repository.
2. Branch: `git checkout -b fix/short-description`.
3. If you're touching a workflow file, test it in your own fork first
   (Actions → run manually) before opening a PR.
4. Open a pull request describing what changed and why.

## Reporting issues

Open a GitHub Issue with what you expected, what actually happened
(screenshots help for rendering issues), and which file/workflow is
involved. Security issues go through `SECURITY.md`, not public issues.
